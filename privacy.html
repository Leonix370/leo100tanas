Privacy Policy

Last updated: November 26, 2026.

What data is used

When the account owner connects their TikTok account, the tool receives an access token and a refresh token, the account's open ID and the granted scopes (user.info.basic, video.upload). No other personal data is collected.

Where it is stored

Tokens are stored only on the account owner's own computer, in a file readable only by them. Nothing is sent to any server other than TikTok's official API. No data is sold, shared or used for advertising or analytics.

What it is used for

Only to upload the owner's own videos to their TikTok drafts and check the upload status.

Deleting data

The owner can revoke access at any time in TikTok (Settings → Security → Manage app permissions) and delete the local token file.
